# Historia y evolución de las Bases de Datos (BD)

## Historia

Las Bases de Datos Relacionales surgieron a finales de la década de 1960, cuando **Edgar F. Codd** introdujo la teoría matemática de las relaciones aplicada al almacenamiento de datos. En **1970** publicó el artículo **"A Relational Model of Data for Large Shared Data Banks"**, donde presentó el **Modelo Relacional**, que revolucionó la forma de organizar y administrar la información. 0

El modelo propuesto por Codd se basa en dos componentes:

- **Estática:** define la estructura de las tablas y las restricciones.
- **Dinámica:** utiliza el álgebra y el cálculo relacional para manipular los datos.

Este modelo está fundamentado en la **teoría de conjuntos** y la **lógica de predicados de primer orden**, permitiendo representar la información de forma organizada mediante tablas relacionadas entre sí. 1

## Evolución de las Bases de Datos

| Año | Evolución |
|------|-----------|
| **1970** | Edgar F. Codd publica las bases del Modelo Relacional. |
| **1971-1972** | Comienzan los primeros desarrollos teóricos del modelo. |
| **1973-1978** | Se crean los primeros prototipos de Sistemas Gestores de Bases de Datos Relacionales (SGBDR): **System R (IBM)** e **Ingres (Berkeley)**. |
| **1978** | IBM presenta el lenguaje **QBE (Query By Example)**. |
| **1979** | Aparece **Oracle**, el primer SGBD comercial que implementa **SQL**. |
| **1981-1984** | Surgen otros gestores importantes como **Informix**, **Sybase** y **DB2 (IBM)**. |
| **1986** | ANSI establece el primer estándar oficial para **SQL**. |
| **1987** | ISO adopta el estándar internacional **SQL (ISO 9075)**. |
| **1992** | Se publica **SQL-92**, mejorando la compatibilidad entre distintos sistemas gestores. |
| **1999** | Llega **SQL:1999**, incorporando características de programación orientada a objetos. |
| **2003** | **SQL:2003** agrega integración con **XML**. |
| **2011** | **SQL:2011** incorpora soporte para bases de datos temporales. |
| **2016** | **SQL:2016** añade soporte para documentos **JSON**. |
| **2023** | **SQL:2023** incorpora soporte para bases de datos de **grafos**. |
